# Person 2 – DARKVERSE

## Backend & Data Analysis Module

This folder contains the backend implementation of DARKVERSE, an intelligent Dark Matter and Galactic Behaviour Analytics Platform.

### Modules
- Physics Model
- Galaxy Rotation Analysis
- Mass Estimation
- Statistical Analysis
- Anomaly Detection

### Project Structure
- `analysis/` – Core analytical modules
- `data/` – Galaxy dataset
- `tests/` – Testing suite
- `requirements.txt` – Python dependencies
